おらマチの遊び方

「おらマチ」は、「はい」「いいえ」の質問に答えていくだけで、おらっちがあなたの思い浮かべた市区町村を当てる無料の地理ゲームです。ここでは、実際の画面に沿った遊び方をご案内します。

基本的な遊びかた

  1. トップページで、全国版・入門版・地域限定版のいずれかを選びます。
  2. 思い浮かべた市区町村(地元でも、好きな街でもかまいません)を1つ決めます。
  3. 表示される質問に、その市区町村にあてはまるかどうかで答えます。
  4. 回答するたびに、候補となる自治体がしぼり込まれていきます。
  5. 十分にしぼり込めたところで、おらっちが自治体を予想します。

各回答ボタンの意味

質問画面には、次の5つの回答ボタンがあります。

  • はい … 思い浮かべた市区町村にあてはまる場合。
  • いいえ … あてはまらない場合。
  • たぶんそう … あてはまる可能性が高いが、確信が持てない場合。
  • たぶん違う … あてはまらない可能性が高いが、確信が持てない場合。
  • わからない・スキップ … 質問の意味が分からない、または判断できない場合。この質問は候補のしぼり込みに使われません。

「たぶんそう」「たぶん違う」は、「はい」「いいえ」よりも弱い情報として扱われます。迷ったときは、無理に「はい」「いいえ」を選ばず、これらのボタンをお使いください。

全国版と地域版の違い

「全国版」は、北方領土の6村を除く全国1,741市区町村(792市・東京23特別区・743町・183村)すべてが対象です。「入門版」は都道府県庁所在地(新宿区を含む)と東京23区の69自治体だけが対象なので、初めての方は対象内の自治体を思い浮かべて遊んでください。「地域版」は、都道府県や地方などエリアを絞ったモードで、そのエリアならではの質問(方言・地域区分・隣接県など)が出題されます。

途中でできること

  • ← 前の質問に戻る … 直前の回答を取り消し、もう一度答え直せます。
  • 📝 これまでの回答 … これまでに答えた質問の一覧を確認できます。回答を間違えたと思ったときは、ここから該当の回答を選び直せます。

正解しなかった場合

候補のしぼり込みが十分に進まないまま質問がなくなると、おらっちが降参する画面になります。この画面では、最後まで候補に残っていた市区町村(おらっちが迷っていた候補)が表示されるほか、「ほんとうのマチを教えてください」フォームから、正解の市区町村を教えていただくことができます。いただいた情報は、データの改善に活用させていただきます。

回答を間違えたと思ったとき

ゲームの途中であれば「← 前の質問に戻る」または「📝 これまでの回答」から回答を訂正できます。正解・不正解の結果が出た後でも、結果画面から「この情報を訂正する」を選ぶと、同じ訂正フォームを開けます。

結果のシェア方法

正解画面の「画像でシェア」を選ぶと、自治体名・質問数・地元がバレた理由(決め手になった回答)を含んだ画像が、お使いの端末上で作成されます。作成した画像は、SNSへの投稿や端末への保存にお使いいただけます。この画像作成処理は端末内で完結しており、外部のサーバーへ送信されることはありません。

全国制覇帳の使い方

正解した市区町村は、お使いの端末に「全国制覇帳」として自動的に記録されます。トップページや結果画面から全国制覇帳を開くと、次のような内容を確認できます。

  • これまでに正解した自治体の一覧
  • 都道府県別・地方別の達成状況
  • 正解回数の多い自治体や、最少質問数などの記録

この記録は端末のブラウザ内(ローカルストレージ)にのみ保存され、外部には送信されません。詳しくはよくある質問もあわせてご覧ください。
