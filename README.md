# おらマチ

**おらマチ**は、Yes / No の質問に答えていくと、あなたのマチを当てる市町村当てゲームです。

日本の地理、交通、文化、方言、名物グルメ、ご当地キャラなどを手がかりに、だんだん候補を絞り込んでいきます。

北方領土の6村を除く、**全国1,741市区町村(792市・東京23特別区・743町・183村)**に対応しています。全国47都道府県のすべての市区町村を収録済みです。

## 公開ページ

https://oramachi-jp.com/

## 遊び方

1. 表示される質問に「はい」「いいえ」で答えます。
2. わからない質問はスキップできます。
3. 候補が絞られると、おらっちがマチを推測します。
4. 当たったら診断カード風の結果画面が表示され、「あなたの地元がバレた理由(地元バレポイント)」が表示されます。
5. 結果は画像または文章でシェアできます。
6. 正解した自治体は「全国制覇帳」に記録されます。

* 全国版で「どの地方(北海道・東北・関東・中部・近畿・中国・四国・九州)にあるか」を尋ねる質問
* 特徴の少ない市にも、その市ならではの名所・名物・施設を尋ねる固有の質問を用意

## cities.jsonのデータ形式について

ファイルサイズを抑えるため、各自治体の`tags`は「trueだったキーだけの配列」で保存しています
(例: `"tags":["coastal","pop100k"]`。falseのタグは配列に含まれません)。

* この形式変更により、ファイルサイズは約9.8MB→約0.38MBに削減されました(約96%減、gzip配信と合わせるとさらに小さくなります)。
* `app.js`は起動時に、この配列形式を自動的に元の`{タグ名: true/false, ...}`というオブジェクト形式へ復元してから使用します。データの意味(どの自治体がどのタグを持つか)は一切変更していません。
* `editor.html`で読み込む際も自動的にオブジェクト形式へ復元され、書き出し時は再び軽量な配列形式で保存されます。手動でJSONを直接編集する場合は、この配列形式を崩さないようご注意ください。

## トラブルシューティング

* **データ読み込み中のまま止まる場合**：`.htaccess`のNginxキャッシュ設定(`Ngx_Cache_StaticMode`等)が、当時10MB近かった`cities.json`の配信に悪影響を与えていた事例があります。リポジトリには無効化した状態(拡張子の無い`htaccess`というファイル名)で保存しています。サーバー側でApacheの設定として反映させたい場合のみ、ファイル名を`.htaccess`に戻してください。現在はタグ配列形式への圧縮により`cities.json`は約0.4MB(gzip後約0.09MB)まで軽量化されているため、当時ほどのリスクは低いと考えられますが、有効化した際は必ず実際の動作を確認してください。
* **「プレイヤーの端末で更新した内容が反映されない」場合**：`.htaccess`(拡張子付きで有効化した場合)には、HTMLファイル(`index.html`等)だけをXserverのサーバーキャッシュ(Xアクセラレータ)から除外する設定を追加してあります。`app.js`/`style.css`/`cities.json`等は`bump-version.js`によって内容が変わるたびにURLの`?v=`が変わるためサーバーキャッシュを効かせても問題ありませんが、`index.html`自体がサーバー側にキャッシュされたままだと、その`?v=`の更新が訪問者に届きません。ファイル名を`.htaccess`に戻すことで、この対策が有効になります(現状は上記の理由で無効化されたままです)。

## データ出典

### 全国制覇帳の日本地図

都道府県の輪郭データには [@svg-maps/japan](https://github.com/VictorCazanave/svg-maps/tree/master/packages/japan)（Victor Cazanave、MapSVGを基に作成）を使用し、日本語名への対応付けとおらマチ用データ形式への変換を行っています。ライセンスは [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) です。

### 人口・面積(統計質問で利用)

各自治体の `stats.population`(人口)・`stats.area_km2`(面積)は、以下を基準にしています。

* 基準年月日: **2025年10月1日**(全自治体で統一)
* 出典: [uub.jp「全国の市区町村 人口・面積・人口密度ランキング」](https://uub.jp/rnk/cktv_j.html)
  * 人口の元データ: 総務省統計局 令和7年国勢調査人口速報値に基づく推計人口
  * 面積の元データ: 国土交通省 国土地理院「全国都道府県市区町村別面積調」(2025年10月1日時点)
* 「東京23区部」(23区全体の集計エントリ)の人口・面積は、23区それぞれの値を合算したもの。
* 通常自治体を対象とした面積順位・人口密度順位・上位/下位20%の分位計算には、「東京23区部」を含めていません。
* stats を設定できなかった自治体はありません(全自治体に適用済み)。
* cities.jsonは1,742レコードで、うち1件はゲーム用の「東京23区部」集約レコードです。実在する自治体は1,741件(792市・東京23特別区・743町・183村)で、この集約レコードは実自治体数・全国制覇帳の母数・都道府県別件数には含めていません。

### 高速道路インターチェンジ(交通質問で利用)

「◯◯道のインターチェンジがある？」という質問で使う各路線のIC所在地は、
各高速道路のWikipediaのIC一覧、NEXCO東日本・国土交通省北海道開発局のプレスリリース、
各IC記事の所在地表記を突き合わせて、収録している市に該当するものだけを設定しています。

* 全国の主要な高速道路(計60路線)に対応しています。北海道・東北・関東・中部・近畿・中国・四国・九州の各地方の高速自動車国道と主要な自動車専用道路を網羅しています(例: 道央道・東北道・関越道・中央道・東名/新東名・名神/新名神・北陸道・山陽道/中国道・高松道・九州道 ほか)。
* 各ICタグ(`ic_*`)は、収録されている市に属するインターチェンジだけをタグ付けしています(所在地が非収録の町村・特別区にあるICは対象外)。
* これらの質問は、その路線が実際に通る地方版と全国版でのみ出題されます。県境をまたぐ路線(東名なら関東・中部の両方、北陸道なら中部・近畿の両方 など)は、通過する複数の地方版で出題されます。他地方版では出題されません。
* 出題する地方の対応は`app.js`の`IC_ROUTE_GROUPS`で一元管理しています。

### 全国制覇帳・設定(localStorage)

* 正解した自治体の記録(`oramachi_conquest_v1`)と、匿名送信のON/OFF設定(`oramachi_settings_v1`)は、
  お使いの端末のブラウザ内(`localStorage`)だけに保存され、外部へは送信されません。
* 自治体の一意キーには、cities.jsonに専用のID列が無いため「都道府県+名前」の組み合わせ(`cityId()`関数)を使っています。
* データが壊れている・バージョンが古い場合は、自動的に初期状態から作り直します(エラーで落ちることはありません)。
* 詳しい送信内容は [privacy.html](./privacy.html) を参照してください。

## 検証用スクリプト(開発者向け・ゲーム本体からは読み込まれません)

Node.js で実行します。ゲーム本体(`app.js` / `cities.json`)からは読み込まれません。

### 自治体データの整合性検証 (`tools/validate-municipalities.js`)

`cities.json` の内容が、全国コンプリート状態として正しいかを自動チェックします。

```
node tools/validate-municipalities.js
```

主な確認項目:

* `cities.json` が 1,742 レコードであること
* ゲーム用「東京23区部」集約レコードがちょうど1件だけ存在し、実自治体1,741件と区別されていること
* 都道府県が 47 であること
* `is_town_village` が 926 件、`is_village` が 183 件であること
* 実自治体の市区町村ID(`都道府県::名前`)の重複が 0 件であること
* `fact` / `food` / `dialect` / `mascot` / `stats`(人口・面積)の欠損が 0 件であること
* 北方領土の6村(色丹村・国後郡泊村・留夜別村・留別村・紗那村・蘂取村)が登録されていないこと
* 各都道府県・地方の町村数が期待値どおりであること
* 同名自治体(美里町・南牧村など)が「(都道府県名)」付きで区別され、ID が一意であること

エラーは0件で通ります。「同一タグ構成」は警告として報告されますが、これはタグ構成が同じでも人口・面積・`is_village`・地域区分などの質問で実プレイ上は区別されるケースであり、エラーではありません(推測でタグや質問を増やすことはしていません)。

### デバッグモード

デバッグパネルが出ます(通常の公開画面には表示されません)。
